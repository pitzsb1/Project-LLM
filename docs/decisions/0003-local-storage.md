# 초기 로컬 저장

- 상태: 확정
- 결정자: 프로젝트 담당 개인(사용자)
- 날짜: 2026-10-28
- 근거: [P1 개인 답변](../open-questions.md), 사용자의 A/A/A/A/A 답변

## 배경
제안서 §4.2의 RAG·과거 분석 자료 저장 방식이 미정이었다.

## 선택지
로컬 JSON / SQLite / 보류

## 선택과 이유
초기 가상 기사·결과는 로컬 JSON에 보관한다. 실제 기사 전문·사용자 입력·실행 로그는 Git에서 제외한다. 실제 기사 보존 기간은 추후 결정한다.

개인은 Q3 A를 선택했다. 개인 이유는 별도로 진술하지 않았다. AI 해석: 초기 규모에서 단순하고 외부 저장 서비스가 필요 없다.

## 영향
저장 로더는 미구현. 원본 로그와 제출용 비식별 요약은 구분한다. 보존·공개 범위 변경은 추가 개인 결정이 필요하다.
