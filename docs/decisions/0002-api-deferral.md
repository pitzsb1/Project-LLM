## 배경
제안서 §4.1~4.2는 모델·검색 사용을 계획하나 실제 모델 ID·검색 제공자·예산은 확인되지 않았다.

## 선택지
초기 미연결 / 제공자·모델·예산을 지금 지정

## 선택과 이유
초기 API를 연결하지 않는다. 연결 전 제공자·실제 모델 ID·요금·예산을 확인한다.

개인은 Q2 A를 선택했다. 개인 이유는 별도로 진술하지 않았다. AI 해석: 비용 없이 환경 준비를 진행할 수 있다.

## 영향
실제 API 통합은 미검증. 제안서의 모델 표기는 검증 전 계획으로 보존하며 $4.50을 승인 예산으로 해석하지 않는다.
