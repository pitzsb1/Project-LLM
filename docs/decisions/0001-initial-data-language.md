# 초기 데이터와 언어

- 상태: 확정
- 결정자: 프로젝트 담당 개인(사용자)
- 날짜: 2026-10-28
- 근거: [P1 개인 답변](../open-questions.md), 사용자의 A/A/A/A/A 답변

## 배경
제안서 §3.1~3.3은 기사 분석을 계획하지만 개발 데이터·언어 정책은 미정이었다.

## 선택지
가상 기사 / 고정 실제 기사 / 실시간 수집; 영어 표본+한국어 보고서 / 복수 언어 / 한국어 가상 표본

## 선택과 이유
초기는 영어로 작성하고 가상임을 명시한 기사, 보고서는 한국어로 한다.

개인은 Q1 A와 Q5 A를 선택했다. 개인이 별도 이유를 진술하지는 않았다. AI 해석: 재현 가능한 초기 검사와 영어 입력·한국어 출력 검증을 준비할 수 있다.

## 영향
실제 수집·다국어 품질은 이후 검증한다. 최종 5개 국가·지역 및 3개 출처 목표는 유지한다.
