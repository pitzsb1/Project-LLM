# 의사결정 기록 기준

## 개인 확인이 필요한 결정
기술 스택/개발 도구 변경, 데이터 출처·언어·저장·공개·보존 정책 변경, 유료 사용과 예산, 실제 외부 서비스 연결, 범위·품질 기준 변경, 배포는 개인에게 선택지·장단점·영향을 제시한다.
이미 허용된 작업의 파일 정리·오탈자·경로 수정·문서 동기화는 AI가 자율 처리한다. 새 결정을 만들기 위해 사소한 작업까지 ADR로 기록하지 않는다.

## 상태와 기록 방법
- 제안: AI가 선택지와 추천을 작성했으나 개인이 확정하지 않음.
- 확정: 개인이 선택했다는 실제 근거가 있음. AI가 대신 결정하지 않음.
- 보류: 필요한 시점 전까지 미정으로 남김.
파일명은 `NNNN-short-title.md`. 형식은 상태, 배경, 선택지, 선택과 이유, 영향, 결정자, 날짜, 답변 근거다. 이유가 개인 발언이 아니라 AI 해석이면 표시한다. 변경 시 이전 결정을 보존하고 후속 ADR과 연결한다.
