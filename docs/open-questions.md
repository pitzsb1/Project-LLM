## Q1. 초기 개발·검사에 어떤 기사 데이터를 사용할까요?

근거: 제안서 §3.1~3.2는 실제 기사 분석을 목표로 하지만 개발용 데이터 정책은 없다.
- A. 명확히 가상으로 표시한 기사만 사용: 비용·네트워크 없이 재현하기 쉽지만 실제 기사 품질을 검증할 수 없다.
- B. 사용 조건을 확인한 실제 기사 표본을 고정: 현실적인 사례지만 원문 보관·공개 범위 확인이 필요하다.
- C. 매번 실시간 기사 수집: 최신 자료를 다룰 수 있지만 비용·접근 실패·결과 변동이 생긴다.
추천: A. 하네스 검사와 실제 뉴스 검증을 분리할 수 있다. 실제 수집 목표는 이후 유지한다.
개인 답변(2026-10-28): A — 가상임을 표시한 기사만 사용.

## Q2. 외부 API 연결 시점과 비용 한도는 어떻게 할까요?

근거: §4.1의 $4.50에는 과금 단위가 없고 §4.2의 검색 제공자는 미정이다.
- A. 초기 환경은 API 미연결, 제공자·실제 모델 ID·요금·예산은 연결 전에 확인: 비용 없이 준비 가능하나 실제 통합 검사는 나중에 한다.
- B. 사용할 검색 제공자와 실제 모델 ID, 1회·전체 예산을 지금 개인이 지정: 통합 준비가 구체적이나 요금 확인과 계정 준비가 필요하다.
추천: A. 모델 표기는 제안서대로 보존하고 실제 API 연결은 별도 결정으로 남긴다.
B 선택 시 검색 제공자 / 실제 모델 ID / 1회 예산 / 전체 예산을 함께 적어 주세요. 키 값은 보내지 마세요.
개인 답변(2026-10-28): A — 초기 API 미연결. 제공자·실제 모델 ID·요금·예산은 연결 전에 확인.

## Q3. 초기 기사 표본·분석 결과·로그를 어디에 얼마나 보관할까요?

근거: §4.2 RAG·과거 분석 자료 활용을 계획하지만 저장 방식과 보존 기간은 없다.
- A. 로컬 JSON 기반, 초기에는 가상 기사와 결과만 보관: 단순하고 재현하기 쉽지만 대량 검색에는 제한이 있다. 실제 기사 전문·사용자 입력·실행 로그는 Git에 올리지 않는다.
- B. 로컬 SQLite: 구조화 조회에 유리하지만 스키마·마이그레이션 관리가 추가된다.
- C. 저장 결정을 보류: 성급한 확정을 피하지만 P4의 저장 관련 환경은 미구성으로 남는다.
추천: A. 초기 하네스 규모에 맞고 외부 저장 서비스가 필요 없다. 실제 기사 보존 기간은 연결 전에 추가 결정한다.
개인 답변(2026-10-28): A — 초기 가상 기사와 결과는 로컬 JSON에 보관. 실제 기사 전문·사용자 입력·실행 로그는 Git에서 제외. 실제 기사 보존 기간은 추후 결정.

## Q4. Python 개발 환경과 의존성 관리는 어떤 방식으로 할까요?

근거: §4.3은 Python 3.11과 라이브러리를 명시하지만 관리 도구는 정하지 않았다. 기존 설정 파일도 확인되지 않았다.
- A. 프로젝트 .venv + pip + 의존성 파일: 기본 도구로 구성할 수 있으나 버전 고정 정책을 별도로 적어야 한다.
- B. uv + 프로젝트 설정·잠금 파일: 재현성 관리가 편하지만 uv 설치 상태 확인과 필요 시 설치가 추가된다.
추천: A. 별도 도구를 추가하지 않고 최소 환경부터 구성할 수 있다. 패키지 설치는 개인 답변 이후 P4에서 한다.
개인 답변(2026-10-28): A — 프로젝트 .venv + pip + 의존성 파일 사용. 설치는 P4에서 진행.

## Q5. 초기 테스트용 기사 언어와 보고서 언어는 무엇으로 할까요?

근거: §2.2의 다국가 비교와 §3.3의 한국어 화면 예시는 있지만 기사 처리·출력 언어는 명시되지 않았다. 참고 보고서의 번역 제안은 확정 사항이 아니다.
- A. 영어 기사 표본 + 한국어 보고서부터 검증: 초기 비교가 단순하지만 현지어 처리 검증은 뒤로 남는다.
- B. 영어·아랍어·히브리어·터키어 등 복수 언어 + 한국어 보고서: 실제 목표에 가깝지만 번역·원문 대조 평가 부담이 크다.
- C. 한국어 가상 기사로 구조 검사만 시작하고 실제 언어 정책은 보류: 비용 없이 준비 가능하나 다국어 품질 검증은 하지 못한다.
추천: C. 이번 초기 검사에 한정한 선택이며, 최종 다국가 수집 범위 축소를 의미하지 않는다.
개인 답변(2026-10-28): A — 영어 기사 표본 + 한국어 보고서. Q1에 따라 초기 영어 표본은 가상 기사로 작성. 실제 기사·다국어 품질 검증은 추후 진행.
